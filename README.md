# Alterius

メールのエイリアス管理するくん

## How to use

Cloudflareにデプロイしてください

Cloudflare Builds では次のコマンドを設定します。

- Build command: `pnpm build`
- Deploy command: `pnpm db:migrate:remote && pnpm deploy:cloudflare`
